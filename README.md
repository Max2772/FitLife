# FitLife Gym - Django сайт тренажерного зала

Лабораторная работа №5 по Django. Веб-приложение для управления тренажерным залом.

## Описание проекта

FitLife Gym - это полнофункциональный веб-сайт тренажерного зала, разработанный на Django 5.2. 
Проект включает в себя систему управления клиентами, тренерами, абонементами, тренировками и отзывами.

## Функциональность

### Для посетителей:
- Просмотр информации о тренажерном зале
- Список тренеров и их специализаций
- Каталог тренировок с фильтрацией по уровню сложности
- Типы абонементов и цены
- Оборудование зала
- Новости и статьи
- FAQ
- Вакансии
- Отзывы клиентов

### Для зарегистрированных клиентов:
- Личный кабинет
- Покупка абонементов с промокодами
- Запись на групповые тренировки
- Выбор персонального тренера
- Добавление отзывов
- История абонементов и тренировок

### Для тренеров (staff):
- Панель управления тренера
- Просмотр своих клиентов
- Управление расписанием тренировок
- Создание промокодов
- Добавление новых тренировок

### Для администраторов:
- Полный доступ к админ-панели Django
- Статистика времени пользователей на сайте (с графиками)
- Диаграмма распределения абонементов
- Управление всеми моделями

## Технологии

- **Backend**: Django 5.2, Python 3.11
- **Frontend**: Bootstrap 5, HTML5, CSS3
- **База данных**: SQLite3
- **Визуализация**: Matplotlib, Pandas
- **Дополнительно**: Django Signals для логирования сессий

## Установка и запуск

### 1. Клонирование репозитория
```bash
cd E:\Programming\Python\Projects\Selected-Chapters-Of-Computer-Science-LB2-5\LB5
```

### 2. Создание виртуального окружения (если не создано)
```bash
python -m venv .venv
.venv\Scripts\activate
```

### 3. Установка зависимостей
```bash
pip install django pillow matplotlib pandas
```

### 4. Применение миграций
```bash
python manage.py migrate
```

### 5. Создание суперпользователя (если не создан)
```bash
python manage.py createsuperuser
```

### 6. Загрузка тестовых данных
```bash
python manage.py load_test_data
```

### 7. Запуск сервера
```bash
python manage.py runserver
```

Сайт будет доступен по адресу: http://127.0.0.1:8000/

## Модели данных

### Основные модели:
- **CompanyInfo** - информация о компании
- **Trainer** - тренеры
- **Client** - клиенты
- **MembershipType** - типы абонементов
- **Membership** - купленные абонементы
- **TrainingType** - типы тренировок
- **Training** - расписание тренировок
- **Equipment** - оборудование
- **Review** - отзывы
- **Promocode** - промокоды
- **FAQ** - часто задаваемые вопросы
- **Article** - новости и статьи
- **Vacancy** - вакансии
- **UserSessionLog** - логи сессий пользователей

## Особенности реализации

### 1. Система аутентификации
- Регистрация с валидацией возраста (16+)
- Валидация белорусских номеров телефонов
- Автоматическое создание профиля клиента при регистрации

### 2. Логирование сессий
- Автоматическое отслеживание времени входа/выхода
- Визуализация статистики через Matplotlib
- Расчет среднего времени на сайте

### 3. Система промокодов
- Скидки на абонементы
- Проверка срока действия
- Привязка к конкретным типам абонементов

### 4. Управление тренировками
- Ограничение количества участников
- Запись на будущие тренировки
- Отмена тренировок

### 5. Отзывы
- Оценка от 1 до 5 звезд
- Привязка к тренерам (опционально)
- Хронологическая сортировка
